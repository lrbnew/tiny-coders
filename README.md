# 🎉 小小程序员养成计划

## 🗺️ 学习路线图

```
🌱 入门          🌿 进阶          🌳 挑战
Scratch  ──▶  Python  ──▶  C++ / 网页制作
图形编程       文字编程          综合项目
```

## 📚 内容导航

| 模块 | 适合年龄 | 内容 |
|------|----------|------|
| [01-scratch](./01-scratch/) | 6–9 岁 | 图形化积木编程 |
| [02-python](./02-python/) | 9–12 岁 | Python 基础编程 |
| [03-cpp](./03-cpp/) | 11–12 岁 | C++ 入门 |

## 🚀 快速开始

1. 根据年龄选择对应模块
2. 打开模块文件夹，阅读里面的 `README.md`
3. 按顺序完成每一关的练习
4. 遇到问题翻阅 [docs/术语表.md](./docs/术语表.md)
