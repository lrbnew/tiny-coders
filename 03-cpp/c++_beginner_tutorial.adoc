= 六年级 C++ 入门小教程：让电脑听你说话
:toc:
:toc-title: 目录
:sectnums:

== 先说一句

C++ 程序有点像给电脑写纸条。

但是电脑比较“认真”：少一个符号，它就可能站在原地不动，像在等你把作业本名字写完整。

本教程只讲几个最常见的小零件：

* 头文件
* `main`
* `iostream`
* `return`
* `cout`
* 花括号
* `int`
* `float`
* `fixed`
* 数学运算
* `abs`
* `sqrt`
* `if`
* `else`

== 第一个完整程序

[source,cpp]
----
#include <iostream>
using namespace std;

int main() {
    cout << "你好，C++！" << endl;

    return 0;
}
----

它运行后会显示：

----
你好，C++！
----

接下来我们把它拆开看。

== 头文件：请工具箱上场

[source,cpp]
----
#include <iostream>
----

这行叫“包含头文件”。

可以把头文件想成工具箱。你要钉钉子，就得先拿锤子；你要让电脑显示文字，就得先请出相关工具。

`#include <iostream>` 的意思大概是：

----
电脑，我要使用输入输出工具，请把 iostream 工具箱拿来。
----

如果没有它，后面的 `cout` 可能就会变成“没带课本还想回答问题”。

=== include 大概有几种

刚开始不用背很多头文件。先知道一件事：

----
#include 是请工具箱，不是写功能本身。
----

从写法上看，常见的 `include` 大概有两种：

[source,cpp]
----
#include <iostream>
#include "my_tools.h"
----

尖括号 `< >` 常用来包含 C++ 自带或安装好的库。双引号 `" "` 常用来包含自己项目里的头文件。

从用途上看，常见头文件可以先分成几类：

[cols="1,2,3", options="header"]
|===
| 类型 | 例子 | 常见用途

| 输入输出
| `<iostream>`
| 使用 `cin`、`cout`、`endl`

| 输出格式
| `<iomanip>`
| 使用 `fixed`、`setprecision` 控制小数显示

| 数学工具
| `<cmath>`
| 使用平方根、幂、四舍五入等数学函数

| 文字工具
| `<string>`
| 使用 `string` 保存一串文字

| 容器工具
| `<vector>`
| 使用 `vector` 保存一排可以变长的数据

| 自己写的工具
| `"student.h"`
| 使用自己项目里写好的函数或类
|===

C++ 标准库里的头文件有很多，不需要一开始数清楚。入门时先记住几个典型的：要输入输出找 `<iostream>`，要控制小数格式找 `<iomanip>`，要做数学计算找 `<cmath>`。

== iostream：输入输出小卖部

`iostream` 可以拆着记：

* `i` 可以理解成 input，输入
* `o` 可以理解成 output，输出
* `stream` 是流，好像水流一样把信息送来送去

所以 `iostream` 负责两件很常见的事：

* 从键盘读东西，比如 `cin`
* 往屏幕写东西，比如 `cout`

在刚入门时，先记住一句话就够了：

----
想让电脑说话，常常要先 include iostream。
----

== main：程序的正门

[source,cpp]
----
int main() {
    ...
}
----

`main` 是程序开始运行的地方。

它像学校大门。上学不能从操场围栏翻进去，程序也通常从 `main` 这里进来。

一个 C++ 程序可以有很多行代码，但电脑会先找 `main`：

----
咦？今天从哪里开始干活？哦，main 在这里。
----

== 花括号：圈出一块地盘

[source,cpp]
----
int main() {
    cout << "你好，C++！" << endl;
    return 0;
}
----

这里的 `{` 和 `}` 叫花括号。

它们像一对围栏，告诉电脑：

----
从这里开始，到这里结束，都是 main 的地盘。
----

如果少写一个花括号，电脑可能会迷路：

----
这里到底结束没有？我该回家了吗？
----

所以写代码时，花括号最好成对出现。

== cout：电脑开口说话

[source,cpp]
----
cout << "你好，C++！" << endl;
----

`cout` 用来把内容显示到屏幕上。

可以把它想成“电脑的小喇叭”。

`<<` 像箭头，表示把右边的东西送到 `cout` 里：

----
cout << "你好";
----

意思就是：

----
把“你好”送到屏幕上显示。
----

`endl` 表示换行。它像告诉电脑：

----
这句话说完了，下一句请另起一行。
----

== int：整数小盒子

[source,cpp]
----
int age = 12;
----

`int` 用来保存整数，比如：

* `0`
* `6`
* `12`
* `100`
* `-3`

它不能很好地保存小数。比如身高 `150.5` 厘米就不是 `int` 最擅长的工作。

可以把 `int age = 12;` 想成：

----
拿一个能装整数的小盒子，名字叫 age，里面放 12。
----

再看一个例子：

[source,cpp]
----
int apples = 5;
int bananas = 3;

cout << apples + bananas << endl;
----

电脑会输出：

----
8
----

因为 5 个苹果加 3 根香蕉，虽然水果开会有点热闹，但数字相加还是 8。

== float：小数小盒子

[source,cpp]
----
float height = 150.5;
----

`float` 用来保存小数，比如：

* `3.14`
* `0.5`
* `98.6`
* `150.5`

可以把 `float height = 150.5;` 想成：

----
拿一个能装小数的小盒子，名字叫 height，里面放 150.5。
----

`float` 适合入门时理解“小数变量”。以后你还会看到 `double`，它也是装小数的盒子，而且通常比 `float` 更精细。

再看一个小例子：

[source,cpp]
----
float price = 2.5;
float count = 3;

cout << price * count << endl;
----

电脑会输出：

----
7.5
----

因为每块饼干 2.5 元，买 3 块就是 7.5 元。

== fixed：让小数乖乖站好

有时候我们希望小数显示得整齐一点。

比如钱常常写成两位小数：

----
7.50
----

不是：

----
7.5
----

这时可以使用 `<iomanip>` 里的 `fixed` 和 `setprecision`：

[source,cpp]
----
#include <iomanip>

cout << fixed << setprecision(2);
cout << 7.5 << endl;
----

`fixed` 的意思可以粗浅理解成：

----
小数点后面固定显示几位。
----

`setprecision(2)` 的意思是：

----
小数点后面显示 2 位。
----

所以它会显示：

----
7.50
----

注意：想使用 `setprecision`，通常要先写：

[source,cpp]
----
#include <iomanip>
----

== 数学运算：让电脑当计算器

C++ 很适合算数。只要符号写对，它算得比同桌按计算器还快。

先看几个最常见的运算符：

[cols="1,2,3", options="header"]
|===
| 符号 | 意思 | 例子

| `+`
| 加法
| `3 + 2` 得到 `5`

| `-`
| 减法
| `8 - 5` 得到 `3`

| `*`
| 乘法
| `4 * 6` 得到 `24`

| `/`
| 除法
| `9 / 2` 如果两个都是整数，会得到 `4`

| `%`
| 取余数
| `9 % 2` 得到 `1`

| `( )`
| 先算括号里
| `(3 + 2) * 4` 得到 `20`
|===

注意：C++ 里的乘号是 `*`，不是数学作业里的 `x`。电脑看到 `x`，会以为那是一个变量名字，可能还会摆出一副“你在叫谁”的表情。

=== 整数除法和余数

[source,cpp]
----
cout << 9 / 2 << endl;
cout << 9 % 2 << endl;
----

输出是：

----
4
1
----

因为 9 除以 2，能分成 4 组，还剩 1。

`/` 负责算“能分几组”，`%` 负责算“还剩几个”。这两个符号经常一起出现，像数学课上坐同桌。

=== abs：求绝对值

绝对值可以先理解成：

----
离 0 有多远。
----

比如 `-6` 和 `6` 离 0 都是 6 格，所以它们的绝对值都是 `6`。

C++ 里可以用 `abs`：

[source,cpp]
----
#include <cmath>

cout << abs(-6) << endl;
----

输出：

----
6
----

`abs` 像一个“负号回收站”：数字走进去，出来时只剩距离，不带脾气。

=== sqrt 与 pow：平方根、乘方与指数的图形魔法

在数学里，我们经常会遇到**乘方**、**指数**和**平方根**。
其实，我们可以用“积木”和“曲线”来直观地感受它们！

==== 1. 平方与平方根 (平方就是拼正方形)

* **平方 (Square)**：就是把一个数乘以自己。比如 `3的平方` (写成 3²) 是 `3 * 3 = 9`。
+
如果用小方块拼，边长是 3 的正方形，一共需要 9 个小方块：
+
----
■ ■ ■
■ ■ ■
■ ■ ■  (边长 3, 总共 9 个)
----
+
在 C++ 里，我们可以用 `pow(3, 2)` 来算 3 的 2 次方(平方)。
* **平方根 (Square Root)**：这是平方的“反向魔法”。如果给你一个有 9 个格子拼成的正方形，问你它的**边长**是多少？
+
边长是 3！所以 `9 的平方根` 是 `3` (写作 √9 = 3)。
+
在 C++ 里，我们用 `sqrt(9)` 来计算平方根。

==== 2. 立方与 3 次方 (立方就是拼 3D 蛋糕)

* **立方 (Cube)**：把一个数连乘三次，比如 `3的立方` (写成 3³) 是 `3 * 3 * 3 = 27`。
+
想象它是一个 3D 立体魔方，每一层是 3*3=9 个积木，一共叠了 3 层：
+
----
第一层：      第二层：      第三层：
■ ■ ■        ■ ■ ■        ■ ■ ■
■ ■ ■        ■ ■ ■        ■ ■ ■
■ ■ ■        ■ ■ ■        ■ ■ ■
----
+
总积木数就是 9 + 9 + 9 = 27 个！在 C++ 里，我们写成 `pow(3, 3)`。

==== 3. 指数与爆炸性增长 (火箭发射！)

* **指数 (Exponent)**：比如 `2的 x 次方` (2^x)。随着 x 越来越大，结果就像火箭发射一样！
  - x = 1 时，2^1 = 2 (刚起步)
  - x = 5 时，2^5 = 32 (开始加速)
  - x = 10 时，2^10 = 1024 (飞出大气层！)
+
在 C++ 里，我们写成 `pow(2, x)`。

为了帮你用最直观的图形看懂这些，我们写了一个超级有趣的图形程序！

[source,cpp]
----
// 你可以编译并运行 09_visual_math.cpp
// 里面有漂亮的 ASCII 字符画：
// - 正方形“平方”阵
// - 3D 蛋糕“立方”层
// - 还有三种曲线的函数图像，看懂它们增长得有多快！
----

我们常用的数学工具总结：

----
abs  绝对值 (负号回收站，只看距离)
sqrt 平方根 (寻找拼出正方形的边长)
pow  几次方 (乘方，例如 pow(底数, 指数))
----

这些工具来自 `<cmath>` 工具箱，所以写程序时千万别忘了加：

[source,cpp]
----
#include <cmath>
----

== if / else：让程序学会看情况

前面的程序大多是“一路跑到底”：

----
先做第一句，再做第二句，再做第三句。
----

但真实生活不是这样。比如：

----
如果作业写完了，就去玩一会儿。
否则，先把作业写完。
----

C++ 里可以用 `if` 和 `else` 表达这种“看情况办事”。

[source,cpp]
----
int homework = 0;

if (homework == 0) {
    cout << "作业清空！文具盒已经开始放假。" << endl;
} else {
    cout << "先写作业，铅笔正在看着你。" << endl;
}
----

可以粗浅理解成：

----
if    如果
else  否则
----

`if` 后面的括号里放“条件”。条件成立，就执行第一块花括号里的代码；条件不成立，就执行 `else` 后面的代码。

=== else if：不止两种情况

有时候事情不只是“是”和“不是”。

比如作业剩几题，可以分成很多档：

[source,cpp]
----
if (homework == 0) {
    cout << "完全写完，可以原地开心三秒。" << endl;
} else if (homework <= 3) {
    cout << "只剩一点点，胜利已经在门口探头。" << endl;
} else if (homework <= 10) {
    cout << "还有一些，先别和沙发深情对视。" << endl;
} else if (homework > 20) {
    cout << "超过 20 题，可能要被打屁股了，赶紧写！" << endl;
} else {
    cout << "任务有点多，建议先打开本子。" << endl;
}
----

可以这样读：

----
如果 homework 等于 0，就……
否则如果 homework 小于等于 3，就……
否则如果 homework 小于等于 10，就……
否则如果 homework 大于 20，就……
否则，就……
----

电脑会从上往下检查。只要遇到第一个成立的条件，就执行那一块，后面的就不看了。

=== 常见比较符号

[cols="1,2,2", options="header"]
|===
| 符号 | 读法 | 例子

| `>`
| 大于
| `homework > 20`

| `>=`
| 大于等于
| `score >= 60`

| `<`
| 小于
| `age < 12`

| `<=`
| 小于等于
| `homework <= 3`

| `==`
| 等于
| `homework == 0`

| `!=`
| 不等于
| `answer != 100`
|===

特别注意：判断“相等”要写两个等号 `==`。

[source,cpp]
----
homework = 0;   // 把 0 放进 homework 盒子里
homework == 0;  // 判断 homework 是不是 0
----

一个等号 `=` 是“放进去”，两个等号 `==` 才是“是不是”。这俩长得像双胞胎，但上课回答问题时可不能互相替考。

== return：报告任务完成

[source,cpp]
----
return 0;
----

`return` 的意思是“返回”。

在 `main` 里面写 `return 0;`，通常表示：

----
报告！程序正常结束，没有摔倒。
----

这里的 `0` 可以先理解成“没问题”。

以后你会看到其他函数也使用 `return`，那时它还可以把计算结果交回去。现在先记住：

----
main 里的 return 0; 经常表示程序顺利结束。
----

== 分号：一句代码的小句号

虽然你没有特别点名它，但它太常出现了，必须偷偷讲一下。

[source,cpp]
----
cout << "你好" << endl;
int age = 12;
return 0;
----

很多 C++ 语句结尾要写分号 `;`。

它像中文句号。你不写，电脑可能会把两句话粘在一起读，然后当场皱眉。

----
