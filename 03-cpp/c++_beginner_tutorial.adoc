= 六年级 C++ 入门小教程：让电脑听你说话

== 先说一句

C++ 程序有点像给电脑写纸条。

但是电脑比较“认真”：少一个符号，它就可能站在原地不动，像在等你把作业本名字写完整。

本教程只讲几个最常见的小零件：

* 头文件
* `main`
* `iostream`
* `return`
* `cout`
* 花括号
* `int`

== 第一个完整程序

[source,cpp]
----
#include <iostream>
using namespace std;

int main() {
    cout << "你好，C++！" << endl;

    return 0;
}
----

它运行后会显示：

----
你好，C++！
----

接下来我们把它拆开看。

== 头文件：请工具箱上场

[source,cpp]
----
#include <iostream>
----

这行叫“包含头文件”。

可以把头文件想成工具箱。你要钉钉子，就得先拿锤子；你要让电脑显示文字，就得先请出相关工具。

`#include <iostream>` 的意思大概是：

----
电脑，我要使用输入输出工具，请把 iostream 工具箱拿来。
----

如果没有它，后面的 `cout` 可能就会变成“没带课本还想回答问题”。

== iostream：输入输出小卖部

`iostream` 可以拆着记：

* `i` 可以理解成 input，输入
* `o` 可以理解成 output，输出
* `stream` 是流，好像水流一样把信息送来送去

所以 `iostream` 负责两件很常见的事：

* 从键盘读东西，比如 `cin`
* 往屏幕写东西，比如 `cout`

在刚入门时，先记住一句话就够了：

----
想让电脑说话，常常要先 include iostream。
----

== main：程序的正门

[source,cpp]
----
int main() {
    ...
}
----

`main` 是程序开始运行的地方。

它像学校大门。上学不能从操场围栏翻进去，程序也通常从 `main` 这里进来。

一个 C++ 程序可以有很多行代码，但电脑会先找 `main`：

----
咦？今天从哪里开始干活？哦，main 在这里。
----

== 花括号：圈出一块地盘

[source,cpp]
----
int main() {
    cout << "你好，C++！" << endl;
    return 0;
}
----

这里的 `{` 和 `}` 叫花括号。

它们像一对围栏，告诉电脑：

----
从这里开始，到这里结束，都是 main 的地盘。
----

如果少写一个花括号，电脑可能会迷路：

----
这里到底结束没有？我该回家了吗？
----

所以写代码时，花括号最好成对出现。

== cout：电脑开口说话

[source,cpp]
----
cout << "你好，C++！" << endl;
----

`cout` 用来把内容显示到屏幕上。

可以把它想成“电脑的小喇叭”。

`<<` 像箭头，表示把右边的东西送到 `cout` 里：

----
cout << "你好";
----

意思就是：

----
把“你好”送到屏幕上显示。
----

`endl` 表示换行。它像告诉电脑：

----
这句话说完了，下一句请另起一行。
----

== int：整数小盒子

[source,cpp]
----
int age = 12;
----

`int` 用来保存整数，比如：

* `0`
* `6`
* `12`
* `100`
* `-3`

它不能很好地保存小数。比如身高 `150.5` 厘米就不是 `int` 最擅长的工作。

可以把 `int age = 12;` 想成：

----
拿一个能装整数的小盒子，名字叫 age，里面放 12。
----

再看一个例子：

[source,cpp]
----
int apples = 5;
int bananas = 3;

cout << apples + bananas << endl;
----

电脑会输出：

----
8
----

因为 5 个苹果加 3 根香蕉，虽然水果开会有点热闹，但数字相加还是 8。

== return：报告任务完成

[source,cpp]
----
return 0;
----

`return` 的意思是“返回”。

在 `main` 里面写 `return 0;`，通常表示：

----
报告！程序正常结束，没有摔倒。
----

这里的 `0` 可以先理解成“没问题”。

以后你会看到其他函数也使用 `return`，那时它还可以把计算结果交回去。现在先记住：

----
main 里的 return 0; 经常表示程序顺利结束。
----

== 分号：一句代码的小句号

虽然你没有特别点名它，但它太常出现了，必须偷偷讲一下。

[source,cpp]
----
cout << "你好" << endl;
int age = 12;
return 0;
----

很多 C++ 语句结尾要写分号 `;`。

它像中文句号。你不写，电脑可能会把两句话粘在一起读，然后当场皱眉。

== 小练习

=== 练习 1：改打招呼

打开 `01_hello.cpp`，把：

[source,cpp]
----
cout << "你好，C++！" << endl;
----

改成你自己的问候，比如：

[source,cpp]
----
cout << "你好，我是代码小队长！" << endl;
----

=== 练习 2：改数字魔术

打开 `02_number_magic.cpp`，把：

[source,cpp]
----
int a = 8;
int b = 3;
----

改成其他整数，看看加减乘除结果怎么变。

=== 练习 3：糖果店老板

运行 `03_candy_shop.cpp`，输入不同的钱数，看看可以买几颗糖。

如果每颗糖涨价了，可以改这一行：

[source,cpp]
----
int price = 2;
----

比如改成：

[source,cpp]
----
int price = 3;
----

== 怎么编译运行

如果电脑里装了 `g++`，可以在 `c++` 文件夹里运行：

[source,bash]
----
g++ 01_hello.cpp -o hello
./hello
----

其他文件也类似：

[source,bash]
----
g++ 03_candy_shop.cpp -o candy
./candy
----

== 最后总结

[cols="1,3", options="header"]
|===
| 名字 | 粗浅理解

| 头文件
| 先把工具箱拿出来

| `iostream`
| 管输入输出的工具箱

| `main`
| 程序开始的正门

| 花括号
| 圈出一块代码地盘

| `cout`
| 让电脑在屏幕上说话

| `int`
| 保存整数的小盒子

| `return`
| 报告程序或函数完成任务
|===

学 C++ 不需要一开始就全懂。先能改、能跑、能看见结果，就已经是在和电脑认真聊天了。
