## 🛠️ 准备工作

### 在线编译器（推荐新手）
- [cplusplus.com/shell](https://cplusplus.com/shell/)
- [onlinegdb.com](https://www.onlinegdb.com/)

### 本地安装
- **Windows**：安装 [Code::Blocks](http://www.codeblocks.org/) 或 [Dev-C++](https://www.bloodshed.net/)
- **Mac**：安装 Xcode Command Line Tools
- **Linux**：`sudo apt install g++`

## 📖 第一个 C++ 程序

```cpp
#include <iostream>
using namespace std;

int main() {
    cout << "你好，世界！" << endl;
    return 0;
}
```
