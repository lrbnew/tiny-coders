# 📝 练习题库

> 各种难度的编程练习题，巩固所学知识！

---

## 📋 难度分类

| 文件夹 | 适合 | 题目数量 |
|--------|------|----------|
| [简单](./简单/) | 完成 Scratch 或 Python 前两关 | 20 题 |
| [中等](./中等/) | 完成 Python 前四关 | 20 题 |
| [挑战](./挑战/) | 完成所有模块 | 10 题 |

---

## 💡 怎么使用题库

1. 根据自己的水平选择难度
2. 打开对应文件夹，找到感兴趣的题目
3. 在自己的文件里写代码
4. 和参考答案比较一下（注意：先自己试试！）

---

## ⭐ 简单题示例

- 打印 1 到 100 的所有数字
- 判断一个数是不是偶数

## ⭐⭐⭐ 挑战题示例

- 实现冒泡排序
