# 🐱 Scratch 图形化编程

> 用积木块搭建你的第一个程序！不需要打字，只需要拖拖拽拽。

---

## ✨ 这一章你会学到

- 认识 Scratch 的编程界面
- 让角色动起来、说话、发出声音
- 用循环让动作重复执行
- 做出属于自己的小游戏！

## 🛠️ 准备工作

1. 打开浏览器，访问 [scratch.mit.edu](https://scratch.mit.edu)
2. 注册一个免费账号（可以请爸爸妈妈帮忙）
3. 点击「创建」开始你的第一个项目！

## ⏱️ 预计学习时间

每个关卡约 **30–45 分钟**，整个模块约 **3–4 小时**。
