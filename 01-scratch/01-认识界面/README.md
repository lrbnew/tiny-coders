# 🔵 关卡 1：认识 Scratch 界面

> 在开始写程序之前，先来认识一下我们的"工作台"！

---

## 🎯 本关目标

- [ ] 知道什么是「舞台」
- [ ] 知道什么是「角色」
- [ ] 找到「积木区」和「脚本区」
- [ ] 运行你的第一个积木

## 📖 课程内容

### Scratch 界面长这样：

```
┌─────────────────────────────────────┐
│  积木区  │    脚本区    │   舞台    │
│ (选积木) │ (拼积木程序) │ (看结果) │
└─────────────────────────────────────┘
```

### 重要概念

| 名称 | 是什么 |
|------|--------|
| **舞台** | 程序运行的地方，就像表演的舞台 |
| **角色** | 舞台上的小演员，比如小猫 |
| **积木** | 一条一条的指令，拼在一起就是程序 |
| **脚本** | 把积木拼好的程序 |

## ✏️ 动手练习

1. 打开 Scratch，找一找上面说的这些部分
2. 点击绿色旗子 ▶，看看会发生什么？
3. 试着拖一个「移动10步」积木到脚本区，再点击它

## 🏆 完成挑战

> 让小猫说一句"你好，我叫 Scratch！"

**提示**：在「外观」积木里找找看 👀
