# 📐 关卡 3：画正方形

> 用循环让画笔自动画出漂亮的正方形！

---

## 🎯 本关目标

- [ ] 学会用「画笔」积木
- [ ] 理解「重复执行N次」
- [ ] 画出一个正方形
- [ ] 挑战：画一个彩色螺旋！

## 📖 课程内容

### 正方形的秘密

正方形有 **4条边**，每条边一样长，每个角都是 **90度**。

所以画正方形只需要：重复 4 次「走一段路 + 转90度」

```
当 ▶ 被点击
落笔
重复执行 4 次
  移动 100 步
  右转 90 度
```

### 激活画笔功能

1. 点击左下角「添加扩展」
2. 选择「画笔」
3. 就能看到画笔积木啦！

## ✏️ 动手练习

1. 添加「画笔」扩展
2. 拼出画正方形的积木
3. 运行，看看画出来了吗？
4. 试试把 100 改成其他数字

## 🏆 完成挑战

> 用循环画一个彩色的正方形螺旋线！

**提示**：每次循环改变一次颜色，让边长慢慢增加 🌈
