# 🐾 关卡 2：小猫走路

> 让 Scratch 的小猫动起来，向右走、向左走，还能循环走！

---

## 🎯 本关目标

- [ ] 让角色向右移动
- [ ] 让角色来回走动
- [ ] 学会使用「重复执行」积木
- [ ] 给移动加上走路动画

## 📖 课程内容

### 让小猫动起来

把下面的积木拼在一起：

```
当 ▶ 被点击
重复执行
  移动 10 步
  碰到边缘就反弹
  将旋转方式设为 左右翻转
```

### 什么是「重复执行」？

就像你一直走路一样，不用每次都说"走一步"，告诉小猫"一直走"就够了！

## ✏️ 动手练习

1. 拼出上面的积木组合
2. 点击 ▶ 运行，看小猫是不是来回走？
3. 把「移动 10 步」改成「移动 50 步」，有什么变化？

## 🏆 完成挑战

> 让小猫走路的同时，每走一步都发出「喵」的声音！

**提示**：在「声音」积木类里找找 🔊
