# 🎮 关卡 4：制作小游戏

> 综合运用前三关的知识，做出第一个完整的小游戏——接苹果！

---

## 🎯 本关目标

- [ ] 让苹果从天上掉下来
- [ ] 用键盘控制篮子左右移动
- [ ] 接到苹果加分，漏掉减血
- [ ] 完成一个可以玩的小游戏！

## 📖 游戏设计

### 游戏规则

- 🍎 苹果从屏幕顶部随机位置掉落
- 🧺 用 ← → 方向键控制篮子
- ✅ 接到苹果：**+1分**
- ❌ 苹果落地：**-1条命**
- 🏁 命用完了，游戏结束

### 需要用到的积木

| 功能 | 积木类型 |
|------|----------|
| 苹果掉落 | 运动 + 控制 |
| 键盘控制 | 侦测 + 运动 |
| 计分 | 变量 |
| 碰撞检测 | 侦测 |

## ✏️ 搭建步骤

1. **创建角色**：添加「苹果」和「篮子」两个角色
2. **苹果脚本**：让苹果每次从顶部随机位置开始往下掉
3. **篮子脚本**：按左键往左，按右键往右
4. **碰撞检测**：苹果碰到篮子加分，碰到底部减命
5. **计分板**：创建「分数」和「生命」两个变量

## 🏆 完成挑战

> 让游戏越玩越难：每得10分，苹果掉落速度加快一点！
