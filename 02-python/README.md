## 🛠️ 准备工作

### 方法一：在线运行（推荐新手）
访问 [python.org/shell](https://www.python.org/shell/) 直接在浏览器里写代码

### 方法二：安装 Python
1. 访问 [python.org](https://www.python.org/downloads/)
2. 下载并安装 Python 3（请爸爸妈妈帮忙）
3. 打开「命令提示符」或「终端」输入 `python` 开始！

## ⏱️ 预计学习时间

每个关卡约 **45–60 分钟**，整个模块约 **6–8 小时**。
