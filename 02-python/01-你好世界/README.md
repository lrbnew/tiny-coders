> 全世界的程序员写的第一个程序，都是让电脑说"Hello, World!"

---

## 🎯 本关目标

- [ ] 运行第一行 Python 代码
- [ ] 学会 `print()` 函数
- [ ] 让电脑输出任何你想说的话
- [ ] 学会写注释

## 📖 课程内容

### 第一行代码

```python
print("你好，世界！")
```

运行结果：
```
你好，世界！
```

### print() 是什么？

`print` 就是"打印"的意思，让电脑把括号里的内容显示出来。

### 注释是什么？

```python
# 这是一行注释，电脑不会执行它
# 注释是用来给人看的说明文字
print("我会写代码了！")  # 这也是注释
```

## ✏️ 动手练习

新建一个文件 `hello.py`，写入以下代码并运行：

```python
# 我的第一个 Python 程序
print("你好，世界！")
print("我叫：____")       # 把____改成你的名字
print("我今年：__ 岁")    # 把__改成你的年龄
```
