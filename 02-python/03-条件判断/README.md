## 📖 课程内容

### if / else 基本用法

```python
温度 = 35

if 温度 > 30:
    print("好热啊，要喝水！")
else:
    print("天气不错！")
```

### 比较符号

| 符号 | 意思 | 例子 |
|------|------|------|
| `>` | 大于 | `5 > 3` → True |
| `<` | 小于 | `2 < 8` → True |
| `>=` | 大于等于 | `5 >= 5` → True |
| `==` | 等于（注意是两个等号！）| `3 == 3` → True |
| `!=` | 不等于 | `1 != 2` → True |

### 多个条件：elif

```python
成绩 = int(input("输入你的成绩："))

if 成绩 >= 90:
    print("优秀！🏆")
elif 成绩 >= 80:
    print("良好！👍")
elif 成绩 >= 60:
    print("及格！📚")
else:
    print("需要加油！💪")
```

## ✏️ 动手练习

```python
# 判断奇数还是偶数
数字 = int(input("输入一个数字："))
if 数字 % 2 == 0:
    print(数字, "是偶数")
else:
    print(数字, "是奇数")
```
