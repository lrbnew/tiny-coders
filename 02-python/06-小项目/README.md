## 📋 项目列表

### 🎲 [猜数字游戏](./猜数字游戏/)

电脑随机生成一个 1–100 的数字，你来猜！
- 猜大了，提示"太大了，再小一点"
- 猜小了，提示"太小了，再大一点"
- 猜对了，显示用了几次猜中

**用到的知识**：变量、条件判断、循环、random 模块

---

### 🎨 [画图小工具](./画图小工具/)

用 Python 的 turtle 模块画出各种图形！
- 画正方形、三角形、圆形
- 画彩色的花朵
- 自定义颜色和大小

**用到的知识**：函数、循环、turtle 模块

---

## 💡 完成项目的建议

1. **先读懂需求**，知道要做什么
2. **拆分步骤**，把大问题分成小问题
3. **一步一步写**，写一点测试一点
4. **遇到错误不要怕**，看看错误信息说的是什么

> 🎉 完成这两个项目，你就是真正的 Python 小程序员了！
