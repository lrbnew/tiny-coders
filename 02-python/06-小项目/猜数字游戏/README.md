# 🎲 项目：猜数字游戏

> 电脑藏一个秘密数字，你能猜到吗？

---

## 🎯 游戏说明

- 电脑在 1–100 之间随机选一个数字
- 你输入你的猜测
- 电脑告诉你猜大了还是猜小了
- 最终猜对后，显示你用了几次

## 💻 完整代码

```python
import random

# 电脑随机生成一个1到100的数
秘密数字 = random.randint(1, 100)
猜测次数 = 0

print("🎲 欢迎玩猜数字游戏！")
print("我在1到100之间想了一个数字，你来猜猜看！")

while True:
    猜测 = int(input("\n请输入你的猜测："))
    猜测次数 += 1

    if 猜测 < 秘密数字:
        print("❌ 太小了！再大一点～")
    elif 猜测 > 秘密数字:
        print("❌ 太大了！再小一点～")
    else:
        print(f"🎉 恭喜你猜对了！答案就是 {秘密数字}！")
        print(f"你一共猜了 {猜测次数} 次。")
        break
```

## 🏆 挑战升级

1. **限制次数**：只给 7 次机会，超过就游戏结束
2. **难度选择**：让玩家选简单（1–10）、普通（1–100）、困难（1–1000）
3. **历史记录**：记录每次游戏的最少猜测次数
