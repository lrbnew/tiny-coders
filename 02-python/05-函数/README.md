## 📖 课程内容

### 为什么需要函数？

```python
# 没有函数：每次问好都要重新写
print("你好！我是小明，很高兴认识你！")
print("你好！我是小明，很高兴认识你！")
print("你好！我是小明，很高兴认识你！")

# 有了函数：定义一次，到处使用
def 打招呼():
    print("你好！我是小明，很高兴认识你！")

打招呼()  # 调用函数
打招呼()
打招呼()
```

### 带参数的函数

```python
def 欢迎(名字):              # 名字是参数
    print("欢迎你，" + 名字 + "！")

欢迎("小红")   # 输出：欢迎你，小红！
欢迎("小刚")   # 输出：欢迎你，小刚！
```

### 带返回值的函数

```python
def 加法(a, b):
    结果 = a + b
    return 结果         # 返回计算结果

答案 = 加法(3, 5)
print("3 + 5 =", 答案)  # 输出：3 + 5 = 8
```

## ✏️ 动手练习

```python
# 写一个判断是否及格的函数
def 是否及格(成绩):
    if 成绩 >= 60:
        return "及格 ✅"
    else:
        return "不及格 ❌"

print(是否及格(85))   # 及格 ✅
print(是否及格(45))   # 不及格 ❌
```
