# 🔢 关卡 2：变量和数字

> 变量就像一个盒子，可以把数字或文字存进去，随时拿出来用！

---

## 🎯 本关目标

- [ ] 理解什么是变量
- [ ] 会做加减乘除运算
- [ ] 学会 `input()` 获取用户输入
- [ ] 完成一个计算器小程序

## 📖 课程内容

### 变量是什么？

```python
苹果数量 = 5       # 把数字5存到"苹果数量"这个盒子里
名字 = "小明"      # 把文字存到"名字"这个盒子里

print(苹果数量)    # 输出：5
print(名字)        # 输出：小明
```

### 数字运算

```python
a = 10
b = 3

print(a + b)   # 加法：13
print(a - b)   # 减法：7
print(a * b)   # 乘法：30
print(a / b)   # 除法：3.333...
print(a // b)  # 整除：3
print(a % b)   # 余数：1
```

### 获取用户输入

```python
名字 = input("请输入你的名字：")
print("你好，" + 名字 + "！")
```

## ✏️ 动手练习

```python
# 练习 1：苹果问题
苹果 = 10
香蕉 = 5
print("我有", 苹果 + 香蕉, "个水果")

# 练习 2：自我介绍
名字 = input("你叫什么名字？")
年龄 = input("你几岁了？")
print("大家好！我叫", 名字, "，今年", 年龄, "岁。")
```
