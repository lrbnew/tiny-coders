# 🎮 趣味小游戏项目

> 用代码做出可以真正玩的游戏！这里的项目综合了所有编程知识。

| 游戏 | 语言 | 难度 | 说明 |

## 🐍 [贪吃蛇](./贪吃蛇/)

用方向键控制蛇吃食物，身体越来越长，不能碰墙或自己！

**用到的技术**：`pygame` 库、列表、游戏循环

---

## 🧱 [打砖块](./打砖块/)

控制挡板让球弹起来打碎所有砖块，经典的 Breakout 游戏！

**用到的技术**：`pygame` 库、碰撞检测、物理运动

---

## ⌨️ [打字练习](./打字练习/)

屏幕上随机显示单词，看你能不能在时间内打出来，练习打字速度！

**用到的技术**：`tkinter` 库、计时器、随机模块

---

## 🛠️ 准备工作

安装 pygame（在终端运行）：

```bash
pip install pygame
```

> 💡 这些游戏代码较多，建议先把 Python 基础学完再来挑战！
