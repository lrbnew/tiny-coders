## 📖 课程内容

### HTML 是什么？

HTML 就像网页的「骨架」，告诉浏览器页面上有什么内容。
每一段内容都用**标签**来标记，标签长这样：`<标签名>内容</标签名>`

### 一个完整的 HTML 文件

```html
<!DOCTYPE html>
<html>
  <head>
    <title>我的第一个网页</title>
  </head>
  <body>
    <h1>你好，世界！</h1>
    <p>这是我用 HTML 写的第一个网页！</p>
  </body>
</html>
```

### 常用标签

| 标签 | 作用 | 例子 |
|------|------|------|
| `<h1>` ~ `<h6>` | 标题（1最大） | `<h1>大标题</h1>` |
| `<p>` | 段落 | `<p>一段文字</p>` |
| `<br>` | 换行 | `第一行<br>第二行` |
| `<b>` | 加粗 | `<b>加粗文字</b>` |
| `<a>` | 链接 | `<a href="网址">点我</a>` |

## ✏️ 动手练习

新建 `index.html`，写一个自我介绍页面：

```html
<!DOCTYPE html>
<html>
  <head>
    <title>我的自我介绍</title>
  </head>
  <body>
    <h1>大家好！</h1>
    <p>我叫 <b>___</b>，今年 __ 岁。</p>
    <p>我最喜欢的事情是：___</p>
    <p>我的梦想是：___</p>
  </body>
</html>
```

## 🏆 完成挑战

> 在页面里加一个链接，点击后跳转到你最喜欢的网站！
