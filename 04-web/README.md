# 🌐 网页制作：HTML & CSS

> 学会制作自己的网页，让全世界都能看到你的作品！

---

## ✨ 这一章你会学到

- 用 HTML 搭建网页的结构
- 用 CSS 给网页加上颜色和样式
- 加入图片和链接
- 制作属于自己的个人主页！

## 🛠️ 准备工作

1. 下载免费编辑器 [VS Code](https://code.visualstudio.com/)
2. 安装插件「Live Server」（在浏览器中实时预览）
3. 新建一个文件夹，在里面创建 `index.html` 文件，就可以开始了！

## ⏱️ 预计学习时间

每个关卡约 **40–60 分钟**，整个模块约 **3–4 小时**。
