# 📖 编程术语表

> 常见编程词汇解释，遇到不懂的词查这里！

---

## A–F

| 术语 | 英文 | 解释 |
|------|------|------|
| **变量** | Variable | 存储数据的"盒子"，有名字和值 |
| **函数** | Function | 一组可以重复使用的代码，用名字来调用 |
| **返回值** | Return Value | 函数运行完后"交还"给调用者的结果 |
| **浮点数** | Float | 带小数点的数字，如 3.14 |
| **编译** | Compile | 把人能读懂的代码翻译成电脑能执行的语言 |

## G–L

| 术语 | 英文 | 解释 |
|------|------|------|
| **函数调用** | Function Call | 使用一个函数，让它执行 |
| **缩进** | Indentation | 代码前面的空格，Python 用它来划分代码块 |
| **整数** | Integer | 不带小数点的整数，如 1, 2, 100 |

## M–R

| 术语 | 英文 | 解释 |
|------|------|------|
| **模块** | Module | 别人写好的代码包，import 进来就能用 |
| **逻辑错误** | Logic Error | 代码能运行，但结果不对 |
| **循环** | Loop | 让一段代码重复执行 |
| **列表** | List | 可以存多个数据的变量，用 `[]` 表示 |

## S–Z

| 术语 | 英文 | 解释 |
|------|------|------|
| **语法错误** | Syntax Error | 代码写法不对，程序无法运行 |
| **条件** | Condition | 判断真假的表达式，用在 if 语句里 |
| **调试** | Debug | 寻找并修复代码中错误的过程 |
| **注释** | Comment | 代码里给人看的说明文字，电脑会忽略 |
| **字符串** | String | 文字类型的数据，用引号包起来 |
| **运行时错误** | Runtime Error | 程序运行中发生的错误 |
