# 👨‍👩‍👧 家长手册

> 了解孩子在学什么，以及如何在家帮助孩子学编程。

---

## 🤔 为什么要学编程？

- 🧠 **锻炼逻辑思维**：编程需要把问题拆分成小步骤，培养系统思考能力
- 🔧 **学会解决问题**：遇到 bug 要调试，培养不放弃的精神
- 🚀 **未来的基础技能**：就像学数学、语文一样，编程正在成为基础素养
- 🎮 **寓教于乐**：做游戏、画图，孩子在玩中学到真本事

## 📋 学习路线

```
🌱 6-9岁：Scratch
   用图形积木编程，零门槛入门

⬇️

🌿 9-12岁：Python
   学真正的编程语言，做出实用的小程序

⬇️

🌳 11-12岁：网页制作 / C++
   更专业的方向，按兴趣选择
```

## 🏠 如何在家辅助学习

### 需要准备的
- 一台电脑（Windows、Mac 都可以）
- 稳定的网络连接
- 每周 2–3 小时的学习时间

### 学习建议
1. **不要帮孩子直接解决问题**，引导他们自己思考
2. 让孩子**给你讲解**他的代码，表达能加深理解
3. **庆祝每一个小成就**，哪怕只是让一行代码成功运行
4. **允许失败**，代码出错是正常的，调试错误本身就是学习

### 学习进度参考

| 阶段 | 标志 | 大概时间 |
|------|------|----------|
| 入门 | 能用 Scratch 做一个简单动画 | 1–2 周 |
| 基础 | 能用 Python 写出猜数字游戏 | 1–2 个月 |
| 进阶 | 能独立完成一个小项目 | 3–6 个月 |

## 📞 遇到问题怎么办？

1. 先让孩子自己尝试搜索解决
2. 查看 [docs/术语表.md](./术语表.md) 了解专业词汇
3. 在仓库提交 Issue 寻求帮助
