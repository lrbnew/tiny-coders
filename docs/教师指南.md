# 📚 教师指南

> 帮助老师更好地使用本仓库开展编程教学。

---

## 🎯 课程目标

通过本课程，学生将能够：
1. 理解编程的基本概念（变量、条件、循环、函数）
2. 独立完成简单的编程项目
3. 培养计算思维和问题分解能力
4. 体验到编程的乐趣和成就感

## 📅 建议课时安排

| 模块 | 建议课时 | 适合年级 |
|------|----------|----------|
| Scratch | 4 课时（每节 45 分钟） | 1–3 年级 |
| Python 基础 | 8 课时 | 4–6 年级 |
| 网页制作 | 4 课时 | 5–6 年级 |
| 小游戏项目 | 4 课时 | 5–6 年级（选修） |

## 👩‍🏫 教学建议

### 课堂节奏
- **讲解**（10分钟）：介绍概念，演示示例
- **跟做**（15分钟）：学生跟着老师一步步操作
- **自做**（15分钟）：学生独立完成练习
- **展示**（5分钟）：请同学展示自己的作品

### 常见问题处理

| 问题 | 应对方法 |
|------|----------|
| 代码有错误 | 引导学生看错误信息，而不是直接告诉答案 |
| 学生跟不上 | 提供「简化版」的练习，降低难度 |
| 学生太快完成 | 引导做「挑战」任务 |
| 不知道从哪开始 | 帮学生把大问题拆分成小步骤 |

## 📊 评估方式

- ✅ 完成度：是否完成了基本任务
- 🎨 创意：是否在基础上做了自己的创新
- 🗣️ 表达：能否用自己的话解释代码的作用
